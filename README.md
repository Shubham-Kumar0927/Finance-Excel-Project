# Finance-Excel-Project
📊 Sales Performance & Price Analysis Dashboard
An interactive Excel Data Analytics dashboard designed to analyze sales performance, product trends, price buckets, and actual vs. rounded sales.

📌 Project Overview

This project focuses on analyzing sales data and converting raw transactional information into an interactive and business-friendly dashboard using Microsoft Excel.
The dashboard provides a consolidated view of sales performance across products, days, regions, and price segments, helping identify important sales patterns and product-level trends.

🎯 Project Objective

The main objective of this project is to:

1. Analyze overall sales performance.

2. Compare actual sales vs. rounded sales.

3. Identify sales contribution across different price buckets.

4. Analyze product-wise sales performance.

5. Compare product sales with average selling price.

   


 Tools & Technologies


🟢 Microsoft Excel	Data analysis & dashboard creation

📊 Pivot Tables	Data summarization

📈 Pivot Charts	Data visualization

🔎 Slicers	Interactive filtering

🎨 Excel Dashboard Design	Business reporting & presentation
